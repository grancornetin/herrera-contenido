# herrera-contenido

Repositorio de **contenido de Herrera Producciones** (arriendo de photobooths y experiencias para eventos, Región del Maule, Chile).

- **Cerebro** (texto): todo lo que un agente necesita saber del negocio para crear contenido. Empezar por [`CLAUDE.md`](CLAUDE.md).
- **`feed/`**: carruseles ya hechos, una carpeta por publicación (`AAAA-MM-DD_tema`).
- **`piezas/`**: lo que se produce semana a semana.
- **`medios/`**: fotos, videos, audios y marca (ver `medios/LEEME.md`).
- **`.claude/`**: skills, agentes y plugins listos para trabajar.
- **`herramientas/`**: utilidades, como sacar enlaces públicos para Metricool.

> Abre esta carpeta en VS Code / Claude Code (o el repo en Claude Code en la nube) y empieza a trabajar: `CLAUDE.md` lo explica todo.
